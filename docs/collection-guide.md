# 固定公众号与抖音使用入口

安装当前分支的 `agent-reach[collection]` 并执行 `agent-reach skill --install`。对Agent说：

- “读取机器之心20篇文章，分析哪些对我有价值。”
- “分析这个抖音博主30条视频，兼顾内容价值和表达方式。”
- “搜索抖音AI Agent最近24小时的5条内容并分析。”
- “获取这个抖音博主全部当前可见作品并分批分析。”

Agent负责桌面搜索与真正的分析；程序负责读取、Get任务续查、抽帧、保存与进度。运行素材命令不等于报告完成。

默认公众号/抖音账号20篇或条；抖音关键词5条且限24小时。公众号全量只覆盖当前目录，未验证完整历史结束信号，状态会保留为部分完成。首次陌生公众号可能需要Agent在微信读书定位并加入书架。

技术输入格式、命令、失败边界见安装包内Skill的 `references/collection.md`。

微信读书正文辅助程序保留独立AGPL-3.0许可证，通过子进程提供服务，未将其重新标注为MIT。位置：`agent_reach/collection/weread_helper`，源码、许可证与修改后的程序一起提供。

已有登录和Get密钥沿用本地配置，不会随安装包或GitHub上传。新下载的视频仅在报告验收后清理；现有文件不自动删除。以后可从报告链接打开文字与关键帧。
