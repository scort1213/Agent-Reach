## 可复现的使用入口

在已配置账号的机器上安装带 collection extra 的包。用户给Agent平台、账号或关键词、数量与分析目标，Agent按Skill先检查连接和登录，再发现、保存、实际审阅并报告。

```bash
agent-reach collect-wechat --help
agent-reach collect-douyin --help
agent-reach read-toutiao-batch --help
agent-reach collection-status --help
```

Command成功或素材准备完成不等于分析完成。真实登录与转写不放CI；不上传凭证、全文或媒体。
