# Bundled collection helper

Agent Reach original code remains MIT. The standalone WeRead helper at `agent_reach/collection/weread_helper` is provided under AGPL-3.0; its full LICENSE and provenance NOTICE accompany the source and wheel. It is invoked as a separate process. This distribution therefore identifies both licenses in package metadata; it does not relabel the helper as MIT.

The helper is adapted from the previously developed WeReadArticleTool, with protocol research based on finlater/weread.koplugin at 2943080c2493a1ae262cc97c74908ed62928c935. This release adds a standalone JSON entry point and collection persistence, retaining the original attribution.
